# Rechly Desktop 1.3.2 — In-App Auto-Update & One-Click Upgrade

This release brings zero-backend in-app auto-updating directly powered by GitHub Releases:

- **Zero-Backend In-App Auto-Update:**
  - Automated non-intrusive background update checks on launch via GitHub Releases.
  - Titlebar notification pill (`🚀 Update v1.3.x verfügbar`) alerting users when a new version is available.
  - Interactive update modal with version details, release notes, and real-time streaming download progress bar (`MB / GB • % • MB/s`).
  - Seamless 1-click update installation on Windows and direct package opening on macOS without manual website downloads.
  - Manual update check button in *Einstellungen* (*Nach Updates suchen*).
  - 100% data safety: All local invoices, client records, and SQLite databases remain completely untouched across updates.
